# Offline educator guided intake
Open `index.html` locally in a browser. The page is self-contained with no external scripts, analytics, persistent storage or application network calls. Network access is blocked by the page Content Security Policy. Browser extensions, clipboard, files and the host computer are outside this application boundary.

Choose one of the available tasks: IEP preparation, Present Levels & Goal, Standards, or After-IEP monitoring. Enter only **fictional or legally/institutionally approved appropriately de-identified** input, not names, DOB, school IDs or a copied student record. Click preview, review missing fields and detected obvious identifiers, confirm privacy, and copy or download one Markdown task handoff. It is **task input for a private conversation**, not persistent Project knowledge and does not itself become an IEP.

The form performs *limited local pattern screening* for obvious email addresses/telephone numbers/student identifiers. It can miss indirect identifiers, re-identification combinations and sensitive narratives. It never certifies de-identification or FERPA compliance. Any substantive legal/IEP answer later generated by the assistant still requires the **live federal and CA Current Guidance Gate**. The offline form cannot check legal updates.

Use an approved local process for protected records. Stop if your district has not approved the selected AI service. Human team review and original official source verification are always required.
