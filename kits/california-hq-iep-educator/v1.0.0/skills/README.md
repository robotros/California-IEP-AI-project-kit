# Optional focused Skills — *separate* from Project knowledge
Each edition has **one** focused Skill: `audit-iep-evidence-and-goal-light` or `audit-iep-evidence-and-goal-full`. Trigger when the user asks to **audit a de-identified IEP goal or five-component evidence linkage**. Do not trigger for unrelated topics, general legal advice, diagnosis, auto-writing student records, or sending an IEP. Project knowledge and account Skills do not synchronize.

For Claude (where user/organization allows native Skills), use `distributions/audit-iep-evidence-and-goal-{light|full}-claude-skill.zip` with a **one-folder wrapper**. For eligible Gemini/Agent Builder Frontier/Copilot Studio GitHub Copilot harness, use `...-root-skill.zip` only if the actual surface accepts root SKILL ZIPs. Some platforms accept a standalone `SKILL.md` by their own UI; check first. For ChatGPT personal plans, use the project `GOAL_AUDIT` procedure fallback. Native import has **not been tested** in any account, and providing the ZIP does not enable the Skill.

Only a safe canonical workflow file is included as byte-identical reference. Other Project data is intentionally omitted. You must supply relevant de-identified inputs and applicable authorized official live sources for any legal claims; the Skill has no built-in browsing or institutional access. Human approval required for actual IEP outcomes.
