# Detailed educator workflows
## Universal sequence
1. Select professional role and phase; limit initial questions to blocking facts. 2. Enforce privacy, trusted input classification and Current Guidance Gate. 3. Keep `source/date/author/context/measure` evidence table. 4. Connect five IEP components. 5. Draft requested document. 6. Audit source accuracy and disputed points. 7. Identify actual human decision owners and next action. Output `DRAFT — HUMAN TEAM REVIEW REQUIRED`.

## Before IEP: preparation
- Educator purpose and meeting type (annual/initial/reevaluation/amendment, *reported only*), agenda draft; verify procedural rights/meeting timelines directly if asked.
- Source inventory using records, interviews/input, observations and tests (RIOT-style evidence prompts), with gaps for each suspected/relevant area; do not infer eligibility or testing consent.
- Student strengths, preferences, academic/functional performance, grade/course expectations, concerns of parent/guardian and child, culturally/linguistically responsive access supports.
- Present-level paragraph: source and date, task/condition/support/prompt, sample denominator/measurement, exact performance, curriculum participation impact, related need.
- Meeting packet: neutral agenda, staff input requests, likely areas of discussion, interpretation/communication accommodations for review; no promise logistics satisfied.

## During IEP: facilitation aide
- Readable agenda; capture who said what only if explicitly provided; never invent attendance, consent, agreement or legally meaningful procedural record.
- Five component coherence matrix to make proposals inspectable; note rationale for options proposed by different participants.
- Separate `ISSUE`, `REPORTED VIEW`, `PROPOSED OPTION`, `TEAM DETERMINATION (only if documented)` and `FOLLOW-UP`. Unresolved discussion not falsely reported as consensus.
- Administrative designee: check evidence of roles and process when provided; offer clarification questions, not unilateral eligibility or FAPE findings.

## After IEP: implementation
- Human-approved IEP items only as input. Convert documented services/accommodations into a *proposed* implementation checklist, staff notification drafting and monitoring schedule; treat missing approvals as blockers.
- Progress tracking with operational measure, periodic samples, consistent support/conditions, parent report interval as actually approved, review threshold as a recommendation.
- Flag missed data, conflicting documentation or apparent lack of progress for human evaluation; do not unilaterally amend goals/services.

## Standards and alignment
- Retrieve official California code and exact subject/grade source (or mark not verified). Show curriculum demand, student access skill and optional local curriculum priority; never counterfeit official CCC/EUs or alternate pathway.
- Handoff verified standards record to goal work only within same authorized chat; elsewhere output manual transfer packet. Existing repo two-specialist separation is retained as a *verification phase*, not claim of an autonomous second AI.

## Goal draft and audit
**Inputs:** dated direct baseline, actual task, denominator or duration, prompted independence, educational impact, goal construct, optional verified standard and available progress measure.
**Draft:** By [date], under [task/condition/material/support/prompt], [fictional alias] will [observable action] at [proposed quantitative target, with documented rationale] across [number/types of samples], measured by [specified repeatable instrument]. If target evidence missing, leave bracketed `PROPOSED — NEEDS TEAM TARGET` not plausible-sounding numbers.
**Audit:** baseline-target construct and unit comparable? one skill? supports defined? sample size? date? parent progress plan? supports considered? alternative standards and transition triggers individually verified? quality result with critical/high/medium gaps.

## Quality review
Crosswalk rows: assessment -> dated present level -> need/impact -> goal -> considered aids/services -> measurement/reporting. Highlight discontinuities. Rate READY FOR TEAM REVIEW only when evidence complete; human sign-off never implied.

## Guidance update review
Identify issue and last recorded official source versions; re-open official IDEA/34 CFR, Ed Code/CCR, current CDE; log publication/effective dates, actual text or interpretation changes, specific affected outputs. No source/version comparison => `CHANGE STATUS UNDETERMINED`; no access => legal status ON HOLD. Draft change proposal, do not alter persistent files.
