# Operating workflows and prompts | Light
## Universal journey procedure
1. Role, IEP task/stage, fictional alias, grade or grade span, subject/domain, local context if approved.
2. Privacy and authority check; Current Guidance Gate on official federal/California sources; record local SELPA status.
3. Classify evidence (dated tests/observations/record review/interview), strengths, family/student input, missing domains, participation and accessibility.
4. Establish present levels using source/date/measure/conditions/prompts; connect to identified educational need.
5. If academic, check actual California state standard title/code via official CDE source; local priority or enabling skill is a *proposal*, not an official standard. If alternate assessment path, refer to team determination and current official guidance.
6. Draft one observable measurable annual goal per construct: By [date], given [conditions/access/prompts], [alias] will [action] at [criterion and consistency], measured by [repeatable method/sampling]. Explain why target is tentative if growth evidence missing; keep measure comparable to baseline.
7. List support/service discussion items only, including possible implementation roles and evidence needed. No service minutes, offer of FAPE, eligibility, placement or consent decisions.
8. Produce a QA table and suggested follow-up; mark team sign-off external.

## Before / during / after
**BEFORE:** evidence inventory; RIOT-style records/interviews/observation/testing prompt; assessment and parent/student input questions; notice/logistics checks subject to live law/local policy; proposed agenda. Do not assume absent information is negative evidence.
**DURING:** accessible neutral agenda, student/parent strengths and priorities, clarification prompts, decisions *reported vs proposed*, dissent/unresolved list, service options for team review. No simulated agreement.
**AFTER:** implementation handoff checklist, goal monitoring method and frequency proposal, owner assignment proposed, parent progress reporting per actually approved IEP, follow-up and status log; no automatic communications or system writes.

## Prompts
- Start: 'As a [role], help me with [stage/task] using only fictional or authorized de-identified facts. Check current federal/California guidance and tell me what still needs verification.'
- Goal: 'Draft one IEP annual goal from [dated baseline], [skill], [supports], [evidence source], [grade]. Compare baseline and target measurements and explain missing facts.'
- Audit: 'Review this de-identified goal/IEP excerpt for measurable baseline, alignment, monitoring, five-component traceability and missing legal-source verification; return FAIL/REVISE/READY FOR TEAM REVIEW and reasons.'
- Meeting: 'Create a before/during/after meeting checklist for [role] without inventing attendance, approvals or notice timing.'
- Standards: 'Verify California standard [code/grade/subject] against live CDE primary source; distinguish actual code from local priority and instructional progression.'
- Update: 'Check federal and California primary authorities for changes affecting [issue] since [last recorded check]; list direct links, effective dates, impact and owner approval needs.'
- Revision: 'Revise draft while preserving observed evidence and human-approved decisions; show change log, assumptions, authority check and open risks.'

## Common deliverable envelope
**DRAFT | status:** READY FOR TEAM REVIEW / PROVISIONAL — MISSING DATA / ON HOLD / NOT READY.
**Guidance gate:** checked sources + access/effective dates + change/no change/not determined + applicable local policy status.
**Evidence ledger:** observed/reported/proposed/unverified.
**Product:** template or analysis.
**Audit:** issue / evidence / severity / next action / approving professional.
