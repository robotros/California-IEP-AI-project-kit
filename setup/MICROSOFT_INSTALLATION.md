# Microsoft 365 Copilot and Copilot Studio deployment

## Agent Builder
Verify Microsoft work tenant, maker rights, source classification, plan, knowledge file cap, Frontier preview participation and embedded-file exposure before installing. Paste selected `PROJECT_INSTRUCTIONS.txt` into Instructions; upload only 3/8 faithful .txt knowledge copies from `adapters/microsoft-365-agent-builder/`. Do not upload .md into a documented .txt-only embedded file surface. Native Skills preview is conditional on Frontier/tenant policy; root-SKILL ZIP may be usable only in an eligible environment. Sharing is an additional explicit user decision. No connector actions are implied.

## Copilot Studio
Select actual Power Platform environment, authenticate appropriately, check DLP, maker and audience permissions, standard or GitHub Copilot harness, consumption charges, allowed knowledge paths and release authority. Standard harness: knowledge/topics and configured tools/flows; never claim native SKILL.md import. GitHub Copilot harness: import standalone root-SKILL package where eligible, after checking provider documentation and UI. Verify source indexing, test injection, denied data and unauthorized external writes. Publishing and channel access are separate approvals.

If account validation is missing, mark NEEDS_VERIFICATION and use no-code manual setup. Do not place student data in shared reusable Skills or publish agents broadly by default.
