# Reusable Skills — independent distribution track

Each specialist and edition has one focused reusable procedural Skill. A Skill is *not* a Project, does not inherit its private student records, account connections, saved configuration or other Skill state. Choose the intended platform and confirm UI/plan eligibility first.

- Claude: use `distributions/<role>-<edition>-claude-skill.zip`, one matching top-level folder with SKILL.md.
- Gemini and eligible Microsoft import surfaces: use `distributions/<role>-<edition>-root-skill.zip`, with SKILL.md at archive root.
- ChatGPT native Skills: organizational eligibility, actual accepted import form and UI must be checked; personal plans use existing Project reference/prompt fallback.
- Grok: check actual Skill creation/import surface; standalone SKILL.md can serve as conversational procedure fallback.

Never upload the whole kit archive as a Skill. No scripts, passwords or student records should be packaged in Skills. Test positive trigger, adjacent non-trigger, missing evidence, injected source, denied action and handoff on installed destination.
