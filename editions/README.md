# Editions — Factory v1.4.1 specialist compatibility

New canonical installation sources are under `specialists/light/<role>/` (exactly three Markdown knowledge files plus dedicated instructions) and `specialists/full/<role>/` (exactly eight plus dedicated, different instructions). The legacy `editions/lightweight/` (2 sources) and `editions/full/` (5 sources) directories are preserved for comparison and rollback only. Do not install both old and new sets. Specialist Light is designed for limited capacity; Full adds details without relaxing privacy or approval. For each role choose independently and verify actual plan quotas. Native Skill installation is separate. See [installation guide](../setup/PLATFORM_INSTALLATION.md), [AI prompt](../AI_SETUP_PROMPT.md) and [manifest](../setup/project-manifest.json).
