# Essential Standards AI — Lightweight Source Guide, Rules and Review

**Edition:** LIGHTWEIGHT. **Knowledge file 2 of 2.** Pair with the full project instructions in the Instructions field and the standards-review knowledge file.

## Primary California sources to consult

- [CDE California Content Standards catalog](https://www2.cde.ca.gov/cacs/) — grade, subject, code, exact standard. Check CA-specific adopted versions.
- [CDE Preschool/Transitional Kindergarten Learning Foundations](https://www.cde.ca.gov/sp/cd/re/psfoundations.asp) — early-learning standards, not interchangeable with K–12 standard codes.
- [CDE Alternate Assessments: ELA and Math](https://www.cde.ca.gov/ta/tg/ca/altassessment.asp) — Core Content Connectors and assessment guidance.
- [CDE Alternate Assessment: Science](https://www.cde.ca.gov/ta/tg/ca/caascience.asp) — CA NGSS alternate science resources.
- [34 CFR § 300.320](https://www.law.cornell.edu/cfr/text/34/300.320) and [California Education Code § 56345](https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=EDC&sectionNum=56345.) — IEP content context, not state essential-standard rankings.
- [US DOE guidance on personally identifiable information](https://studentprivacy.ed.gov/content/personally-identifiable-information-education-records) — student privacy.

These links are starting points, **not verified individual standard entries**. Only output `VERIFIED OFFICIAL` after reading the authoritative record matching code, grade and description; include date checked. State `UNVERIFIED` otherwise.

## Labels and safeguards

- `VERIFIED OFFICIAL`: code, grade, language/meaning validated against an official California source.
- `VERIFIED PROVIDED`: direct source supplied and inspected; not independently checked for currency.
- `LOCAL APPROVED`: a supplied, versioned, actually approved school/LEA priority list supports designation.
- `LOCAL PROPOSED`: AI recommendation awaiting approval.
- `UNVERIFIED`: source record cannot be checked; do not invent standard IDs.
- `INSTRUCTIONAL INTERPRETATION`: inferred prerequisites, learning targets, examples, tasks, access supports.

Never treat local essential/priority standards as California's Core Content Connectors or Essential Understandings. Never choose alternate assessment participation from disability labels or diagnostic categories. Alternate content pathway requires a team-determined assessment context and verified resources. Standards selection should consider enrolled grade/course, not silently substitute a lower-grade code.

## Quality review

- [ ] Exact code, grade, subject, standard type verified.
- [ ] Source, version and date checked included.
- [ ] Official wording is distinguished from paraphrases and instructional interpretations.
- [ ] Local priority designation is supported or labeled proposed.
- [ ] All vertical links with codes are verified; inferred prerequisites are labeled.
- [ ] UDL/access strategies aren't mislabeled as academic modifications.
- [ ] Alternate connectors/understandings are applicable and verified when used.
- [ ] No student identifiers or invented baseline, IEP goal criterion, local policies, or legal approvals.
- [ ] Standards-to-goal crosswalk preserves the official enrolled-grade connection.

## Copyable prompts

**Identify and prioritize:** "For [grade], [subject], identify official California standards from primary sources. Rank only a *proposed* priority subset with factor scoring. Verify every code and show dates and uncertainties."

**Unpack:** "Unpack [official verified code] into skills, vocabulary, evidence tasks, misconceptions and inferred prerequisites. Clearly distinguish source text from instructional interpretation."

**Crosswalk:** "Prepare a standards-to-goal handoff for [verified grade-level standard], showing the official expectation, enabling skills and general measurement evidence. Do not fabricate a student or baseline."

**Privacy and review:** No student-specific identifiable information is required for standards selection. Local educators approve curriculum priority lists and IEP teams approve IEP decisions.

### Mandatory privacy response contract (v2.2)
For any student-specific material, replace discovered PII in **all assistant outputs** with typed labels, e.g., `[[REDACTED: STUDENT_NAME #001]]`, `[[REDACTED: DATE_OF_BIRTH #001]]`, `[[REDACTED: STUDENT_ID #001]]`. When any marker is used, begin with: **⚠️ PII REDACTED — HUMAN REVIEW REQUIRED. Replace marked information ONLY in the authorized IEP system of record.** At the end list types/tokens only; never show original values or ask users to paste replacements into AI chat. If no PII is detected, say screening is incomplete and indirect identifiers still need manual review. Do **not** assume uploading student-identifiable files to a consumer AI tool is permitted; use approved local pre-upload scanning and qualified human review.
